#  Gestor de Notas

Un elegante y minimalista gestor de notas web estilo "tablero" (dashboard) con soporte para modo oscuro. Este mini proyecto fue diseñado y desarrollado para ofrecer una experiencia de usuario fluida a la hora de apuntar, organizar y priorizar ideas.

##  Funcionalidades principales

* **Creación de notas:** Añade notas con título y descripciones multilínea.
* **Sistema de prioridad:** Marca las notas como "Importantes" para que destaquen con un borde naranja (`#fca311`) y se fijen automáticamente en la parte superior del tablero.
* **Diseño Responsive Grid:** Las notas se organizan automáticamente en columnas fluidas según el tamaño de la pantalla, manteniendo la tarjeta de creación siempre accesible como el primer elemento.
* **Expansión inteligente de texto:** Los textos muy largos se truncan automáticamente a 4 líneas con puntos suspensivos (`...`). Un simple clic sobre el texto expande o contrae la nota, adaptando la cuadrícula de forma dinámica.
* **Persistencia de datos:** Todo se guarda en el `localStorage` del navegador. Tus notas seguirán ahí aunque cierres o recargues la página.

##  Cómo clonar y ejecutar en otra máquina

Si quieres descargar este proyecto en otro ordenador y probarlo localmente, sigue estos pasos:

1. **Abre tu terminal** (Git Bash, CMD, o la terminal de tu editor).
2. **Navega a la carpeta** donde quieras guardar el proyecto:
   
   ```
   cd ruta/a/tu/carpeta
   ```
3. Y ejecuta este comando:
   ```
   git clone [ [https://github.com/TuUsuario/gestor_notas.git](https://github.com/EnmanueFeliciano/gestor_notas.git)](https://github.com/EnmanuelFL/mini_gestor_notas.git)
   ```
4. Una vez completado el paso 3, solo accedes al proyecto:
   ```
    cd mini_gestor_notas
   ```
